Exercícios de Python 

Repositório criado para registrar minha evolução durante os estudos de Python, reunindo exercícios práticos desenvolvidos ao longo do aprendizado da linguagem.

Os arquivos deste repositório seguem a numeração dos exercícios realizados durante os estudos, como "Ex028.py", "Ex029.py", "Ex030.py" e assim por diante.

📚 Conteúdos estudados

Durante os exercícios, foram praticados diversos conceitos fundamentais de Python, incluindo:

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores aritméticos
- Strings
- Estruturas condicionais ("if", "elif", "else")
- Estruturas de repetição ("for" e "while")
- Listas
- Tuplas
- Dicionários
- Funções
- Módulos e bibliotecas
- Manipulação e tratamento de dados
- Outros fundamentos da linguagem Python
